# Support / Soporte

Hi! 👋 This page tells you where to ask for help with Real Fenix Failures. You can write in **English or Spanish** — both are welcome everywhere.

¡Hola! 👋 Esta página te dice dónde pedir ayuda con Real Fenix Failures. Podés escribir en **inglés o español** — ambos son bienvenidos en todos lados.

## Before asking / Antes de preguntar

Many answers are already written down / Muchas respuestas ya están escritas:

1. **[README](README.md)** ([Español](README.es.md)) — what the app does, download, requirements.
2. **[docs/](docs/README.md)** — internal technical documentation (in Spanish), including the [Fenix API integration](docs/integraciones/fenix-api.md) (how to enable the local API, port 8083).
3. **Existing [Q&A](https://github.com/mathi0101/Fenix-Failures-Dispatcher/discussions/categories/q-a) threads** — search first; if you find yours, add a 👍 / buscá primero; si encontrás la tuya, sumá un 👍.

## Where to ask / Dónde preguntar

| Situation / Situación | Channel / Canal |
|---|---|
| "How do I...?" (install, configure, use) / "¿Cómo hago para...?" (instalar, configurar, usar) | [Q&A in Discussions](https://github.com/mathi0101/Fenix-Failures-Dispatcher/discussions/categories/q-a) |
| The app doesn't work as expected / La app no funciona como debería | [Bug report (Issues)](https://github.com/mathi0101/Fenix-Failures-Dispatcher/issues/new/choose) |
| I have an idea / Tengo una idea | [Ideas in Discussions](https://github.com/mathi0101/Fenix-Failures-Dispatcher/discussions/categories/ideas) |
| Security problem / Problema de seguridad | [SECURITY.md](SECURITY.md) (private / privado) |

## When you ask, include / Cuando preguntes, incluí

- **App version** (e.g. `v0.4.1-beta.1`) / **Versión de la app** (ej. `v0.4.1-beta.1`)
- **Simulator** (MSFS 2020 / 2024) and aircraft / **Simulador** (MSFS 2020 / 2024) y avión
- What you tried and what happened / Qué probaste y qué pasó
- The app log for the day, if something failed: `%AppData%\RealFenixFailures\logs\` / El log del día de la app, si algo falló: `%AppData%\RealFenixFailures\logs\`

## Response times / Tiempos de respuesta

This project is maintained by **one person, best effort** — there is no SLA. Bugs with a good reproduction and attached logs get fixed much faster than vague reports. Thanks for your patience! ✈️

Este proyecto lo mantiene **una sola persona, con el mejor esfuerzo posible** — no hay SLA. Los bugs con buena reproducción y logs adjuntos salen mucho más rápido que los reportes vagos. ¡Gracias por tu paciencia! ✈️
