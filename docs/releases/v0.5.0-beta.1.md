# v0.5.0-beta.1

Esta versión afina la calibración de los perfiles de riesgo, corrige cómo abre la ventana principal, estrena un nombre más claro para el ejecutable y deja registrada la versión de la app en cada instalación, como base para actualizaciones internas más inteligentes más adelante.

## Novedades

- **El programa ahora se llama `RealFenixFailures.exe`** (antes `RealFenixFailures.UI.exe`). Es la misma aplicación de siempre, con un nombre más claro. Ojo al actualizar: si tenés un acceso directo, apuntalo al archivo nuevo.
- **Estadísticas de uso anónimas más completas**: cuentan de forma anónima cómo se usa la app para mejorarla en cada versión. Nunca incluyen datos de vuelo ni información personal, y podés apagarlas cuando quieras desde la configuración.

## Mejoras

- **Perfiles recalibrados**:
  - **Bajo** es un poco más activo que antes: ya no tan silencioso.
  - **Alto** y **Squawk 7700** son marcadamente más frecuentes: ahora se sienten como lo que prometen.
  - **Moderado** queda igual.
  - **El desgaste amplifica parejo**: el riesgo extra por el desgaste acumulado de tu aeronave ahora es casi el mismo en todos los perfiles; antes, los perfiles altos lo multiplicaban mucho más.
- **Historial de versiones de la instalación** (mejora interna): la base de datos local registra ahora qué versión de la app la abrió cada vez, con fecha. No cambia nada a la vista, pero prepara el terreno para que las próximas versiones puedan refrescar datos internos (como el catálogo de fallas) automáticamente al actualizar.

## Comunidad

- **Reportar problemas y proponer ideas, más fácil**: nuevos formularios guiados para bugs y sugerencias (en inglés y español), README en ambos idiomas y guía de contribución. Si algo te falló, el formulario te pide exactamente lo que hace falta para reproducirlo.

## Correcciones

- La ventana principal vuelve a abrir en primer plano: después del splash podía quedar detrás de otra ventana y sin foco.

## Actualización

- Instalá encima como siempre (reemplazar los archivos del ZIP). **El ejecutable cambió de nombre** a `RealFenixFailures.exe`: actualizá tus accesos directos y borrá el `RealFenixFailures.UI.exe` viejo si quedó.
- La base de datos se actualiza sola en el primer arranque: se agrega la tabla del historial de versiones y se conserva todo lo demás (sesiones, desgaste, aeronaves, fallas).
- Esta es una pre-release del canal de testers: la pestaña de Actualizaciones la muestra como tal.
